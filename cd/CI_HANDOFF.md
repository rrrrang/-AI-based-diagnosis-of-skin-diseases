# CI 담당자에게 전달할 내용

CI에서 빌드가 끝나면 Jenkins가 자동으로 배포를 시작하게 연결하려고 합니다. 아래 두 가지 부탁드립니다.

1. `SkinAI-Release-CI`에서 성공한 **빌드 번호**를 알려 주세요. 그 빌드에 `release.json`이 있는지 확인해 주세요. 이 파일에는 배포할 이미지 4개와 빌드에 사용한 코드 버전(커밋)이 들어갑니다.
2. CD 코드가 `main`에 합쳐지면 Jenkins에 **`SkinAI-Service-CD`**라는 새 작업을 만들어 주세요. `main`의 `cd/Jenkinsfile`을 연결하고, 새 작업이 성공한 CI 빌드의 `release.json`을 가져갈 수 있게 권한을 주세요.

연결이 끝나면 CD 쪽에서 **CI 성공 후 자동으로 배포가 시작되는지** 확인하겠습니다. 배포한 버전에 맞춰 **사진 접수 → AI 분석 → 의사 확정 → 환자 결과 조회**까지 검사하겠습니다. 배포에 실패하면 직전 버전으로 되돌린 뒤에도 같은 흐름을 다시 확인하겠습니다.
